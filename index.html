ClassSenseAI — Face Recognition & Attentiveness Monitoring for E-Classrooms

Source

Problem

Instructors in online classes have no reliable way to tell when students disengage, making it hard to intervene in time.

Solution

Built a Flask-based system that detects faces via MediaPipe FaceLandmarker, estimates head pose to flag attentiveness, and classifies emotion in real time using an MTCNN + mini-Xception CNN — giving instructors a live dashboard of presence, attention, and engagement.
